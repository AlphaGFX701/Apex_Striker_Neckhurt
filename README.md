# Gyro Space Lab

เกมยานอวกาศ 2D สำหรับทดสอบการเอียงมือถือ โดยใช้ Phaser, TypeScript และ Vite

## รันในเครื่อง

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงบนคอมเพื่อทดสอบด้วยเมาส์หรือปุ่มลูกศร เซนเซอร์บนมือถือจำเป็นต้องเปิดเว็บผ่าน **HTTPS** (ลิงก์เว็บที่เผยแพร่) กด **เปิดเซนเซอร์** แล้วถือเครื่องในท่าถนัดและกด **ตั้งศูนย์** ก่อนเริ่มบิน

```bash
npm test
npm run build
```

ข้อมูลเซนเซอร์ประมวลผลในเบราว์เซอร์เท่านั้น ไม่มีบัญชีผู้ใช้หรือ API สำหรับส่งข้อมูลเซนเซอร์
